# Anjali Polasani — Portfolio

A beautiful, modern portfolio website for Anjali Polasani, Frontend Engineer.

## 🚀 How to Use

Simply open `index.html` in your browser — no build step required!

## 🎨 Design

- **Theme**: Warm editorial aesthetic with cream, rose & ink palette
- **Fonts**: Playfair Display (headings) + DM Sans (body)
- **Effects**: Scroll animations, hover interactions, noise texture overlay

## 📋 Sections

- **Hero** — Name, tagline, CTA buttons
- **About Me** — Bio, stats (years, projects, clients)
- **Tech Stack** — React.js, Tailwind CSS, JavaScript, HTML, CSS, TypeScript, Git, Figma
- **Work Experience** — Timeline with 3 roles
- **Projects** — 3 featured project cards
- **Education** — Degrees and certifications
- **Contact** — Email + social links

## ✏️ Customize

Edit `index.html` to update:
- Your email address (search for `anjali.polasani@email.com`)
- Social links (LinkedIn, GitHub, Twitter, Behance)
- Work experience details
- Project descriptions
- Education background

## 🛠 Tech Used

Plain HTML, CSS, and JavaScript with:
- Tailwind CSS (CDN)
- Google Fonts (Playfair Display + DM Sans)
